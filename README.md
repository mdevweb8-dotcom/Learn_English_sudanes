# Friendly Fluency Hub

تطبيق **Friendly Fluency Hub** لتعلم اللغة الإنجليزية من مستوى **A1** حتى **C2** بواجهة عربية متكاملة (RTL)، يعمل أونلاين وأوفلاين كتطبيق ويب تقدمي (**PWA**) وتطبيق أندرويد أصلي عبر **Capacitor**.

---

## المزايا الرئيسية

1. **نظام مستويات CEFR صارم (`A1` إلى `C2`)**:
   - 6 مستويات، كل مستوى يحتوي على **8 دروس متكاملة** (شرح وقواعد + مفردات + نطق + تمارين + اختبار نهائي للدرس).
   - **قاعدة القفل الصارمة**: لا يفتح المستوى التالي إلا بعد إكمال 100% من دروس المستوى الحالي + اجتياز **الامتحان النهائي للمستوى** (20 سؤالاً متضمناً 3 اختبارات نطق) بنسبة **70% فأكثر**.
   - عزل تام للأسئلة (`question.lesson_id == current_lesson_id`) بحيث لا تظهر أي أسئلة من دروس قادمة.
2. **محرك أسئلة ذكي بدون أخطاء**:
   - قفل فوري لكل الاختيارات بمجرد الضغط على **تأكيد الإجابة**.
   - احتساب الخطأ مرة واحدة فقط لكل محاولة.
   - إعادة طرح أي سؤال خاطئ تلقائياً **بعد 3 أسئلة بالضبط** حتى يتقنه المتعلم.
3. **مختبر النطق (`PronunciationLab`)**:
   - استماع عبر `speechSynthesis` + تقييم فوري للنطق عبر `Web Speech API (SpeechRecognition)` بدرجة من `0` إلى `100` (`ممتاز / جيد / حاول مرة أخرى`).
   - بديل التقييم الذاتي **"سمعت نفسي"** عندما لا يدعم المتصفح التسجيل الصوتي.
4. **نظام تتبع ذكي للمهارات الست**:
   - تتبع `المفردات، القواعد، النطق، الاستماع، إنشاء الجمل، القراءة` مع رسم بياني لنقاط القوة والضعف، وتشجيع إيجابي دائم، و**مراجعة ذكية يومية (10 أسئلة)** تركز تلقائياً على أضعف مهارتين (بما فيها تخصيص 60% للنطق إذا كان أقل من 50%).
5. **المنافسون، تحدي اليوم، والأصدقاء الحقيقيون**:
   - 5 منافسين (`سارة، أحمد، ليلى، عمر، نور`) ينافسونك في مستواك الحالي فقط، مع إشعارات فورية عند التجاوز وسباق **تحدي اليوم**.
   - إمكانية مشاركة **كود التحدي (`FFH-...`)** للمقارنة مع الأصدقاء الحقيقيين بدون سيرفر.
6. **Gamification + المعلم السوداني الذكي + وضع الأطفال/الكبار + أوفلاين كامل**:
   - نقاط `XP` و`Coins` و`Streak 🔥` وشارات إنجاز ومتجر لشراء الثيمات والأفاتار والألقاب.
   - نافذة **اسأل المعلم** تشرح الكلمات والقواعد باللهجة السودانية البسيطة عبر الخادم أوفلاين تلقائياً.
   - تحميل حزم المستويات للعمل **أوفلاين بالكامل** عبر `IndexedDB` + `localStorage` + `Service Worker`.

## التشغيل المحلي

```bash
npm install --legacy-peer-deps
npm run dev
```

- افتح المتصفح على `http://localhost:3000`.
- لتفعيل المعلم الذكي أونلاين، أضف `GEMINI_API_KEY` في متغيرات البيئة (`.env`). عند غيابه أو انقطاع الشبكة يعمل الشرح المحلي السوداني تلقائياً.

npm run generate-icons

## ⚠️ تحذيرات مهمة لبناء Android و GitHub Actions

- **لا تغيّر إعدادات SDK في `android/variables.gradle`**: يجب أن تبقى **`minSdkVersion = 24`** و **`compileSdkVersion = 36`** و **`targetSdkVersion = 35`** بدون تكرار أي متغير داخل الملف.
- **لا تستخدم `android-actions/setup-android@v3`** في ملف `.github/workflows/build-apk.yml`؛ استخدم SDK المثبت مسبقاً على `ubuntu-latest` مع **Java 21 (`zulu`)**.
- **استخدم دائماً `npm install --legacy-peer-deps`** في بيئة CI وتجنّب `npm ci` أو تفعيل **`cache: npm`** في `actions/setup-node@v4` لتفادي تعارضات الاعتماديات.
- **تأكد من عدم حذف `android/settings.gradle`** الذي يربط `:capacitor-android` وجميع إضافات `@capacitor/*` الموجودة في `package.json`.
- **تم التحقق التلقائي** عبر سكربت `npm run verify-android-config` قبل بناء الحزمة.
